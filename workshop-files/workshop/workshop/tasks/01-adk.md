## 1.1 Первый LlmAgent

**Шаги:**

1. Открой `examples/01-adk/starter/hello-agent.ts`
2. Заполни TODO: создай агента (`LlmAgent`), задай вопрос, запусти и выведи ответ
3. Инструкция — на русском (это то, о чём мы его будем спрашивать)

**Результат:** агент отвечает в терминале на твой вопрос.

```bash
npx tsx examples/01-adk/starter/hello-agent.ts
# → агент: "Привет! Я твой первый ADK агент..."
```

> Скелет: `examples/01-adk/starter/hello-agent.ts`

## 1.2 FunctionTool — агент с инструментом

**Шаги:**

1. Открой `examples/01-adk/starter/tool-agent.ts`
2. Напиши `FunctionTool` который принимает `{ city: string }` и возвращает фейковую погоду
3. Подключи инструмент к агенту через `tools: [weatherTool]`
4. Спроси агента: *"Какая погода в Москве?"*
5. Убедись что агент **вызвал инструмент**, а не придумал ответ

**Результат:** в логах видно `[tool called] getWeather({ city: "Москва" })`.

```bash
npx tsx examples/01-adk/starter/tool-agent.ts
# → [tool called] getWeather({ city: "Москва" })
# → агент: "В Москве сейчас 18°C и облачно"
```

> Скелет: `examples/01-adk/starter/tool-agent.ts`

## 1.3 SequentialAgent — два агента в цепочке

**Шаги:**

1. Открой `examples/01-adk/starter/sequential.ts`
2. Напиши **Агент-исследователь**: принимает тему, возвращает 3 факта в JSON
3. Напиши **Агент-редактор**: принимает факты, переписывает в один абзац
4. Оберни обоих в `SequentialAgent`
5. Запусти с темой `"квантовые компьютеры"`

**Результат:** в терминале сначала появляются факты, потом готовый абзац.

```bash
npx tsx examples/01-adk/starter/sequential.ts "квантовые компьютеры"
# → [researcher] { facts: [...] }
# → [editor] "Квантовые компьютеры используют..."
```

> Скелет: `examples/01-adk/starter/sequential.ts`

## 1.4 ParallelAgent — бонус ⚡

**Шаги:**

1. Открой `examples/01-adk/starter/parallel.ts`
2. Допиши агента A и агента B — каждый со своей фиксированной темой в
   instruction (у `ParallelAgent` один запрос уходит сразу всем суб-агентам —
   тему нельзя передать по-разному каждому в рантайме)
3. Оберни оба в `ParallelAgent`
4. Замерь время через `console.time` — сравни с последовательным запуском

**Результат:** оба агента отрабатывают одновременно, время заметно меньше.

> На Gemini и Kitana/claude — реальный параллелизм (сетевые вызовы). На
> Ollama (локальная модель) ускорения не будет — один физический GPU/CPU
> обслуживает оба запроса по очереди, это нормально, не баг.

> Скелет: `examples/01-adk/starter/parallel.ts`
