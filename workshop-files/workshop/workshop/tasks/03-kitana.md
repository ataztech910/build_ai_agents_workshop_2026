# Волна 3 — ADK + Kitana SDK
> ~25 минут · без API ключей · CLI провайдеры

> **Kitana** — обёртка над локальными AI CLI.  
> Нужен хотя бы один из: `claude`, `ollama`, `gemini` в терминале.

```bash
# Проверь что есть:
claude --version      # Claude Code
ollama --version      # Ollama
gemini --version      # Gemini CLI
```

---

## 3.1 Kitana detector — что установлено

**Шаги:**

1. Создай файл `src/09-detector.ts`
2. Импортируй `KitanaDetector` из `@kitana-sdk/core`
3. Вызови `detector.scan()` — получи список доступных провайдеров
4. Выведи таблицу: провайдер / версия / авторизован / модели

**Результат:**

```bash
npx tsx src/09-detector.ts

# ┌───────────┬─────────┬──────────────┬─────────────────┐
# │ provider  │ version │ authorized   │ models          │
# ├───────────┼─────────┼──────────────┼─────────────────┤
# │ claude    │ 1.0.3   │ ✅ yes       │ claude-sonnet   │
# │ ollama    │ 0.3.12  │ ✅ running   │ llama3.2, phi3  │
# │ gemini    │ -       │ ❌ not found │ -               │
# └───────────┴─────────┴──────────────┴─────────────────┘
```

> Скелет: `examples/03-kitana/detector.ts`

## 3.2 Kitana runner — CLI без API ключа

**Шаги:**

1. Создай файл `src/10-runner.ts`
2. Создай `new Kitana({ providers: ['claude', 'ollama'] })`
3. Вызови `ai.ask("Объясни что такое ИИ агент в двух предложениях")`
4. Выведи: текст ответа, какой провайдер ответил, сколько токенов

**Результат:**

```bash
npx tsx src/10-runner.ts
# → provider: claude
# → tokens: 142
# → "ИИ агент — это программа которая..."
```

> Скелет: `examples/03-kitana/runner.ts`

## 3.3 Kitana failover — цепочка провайдеров

**Шаги:**

1. Создай файл `src/11-failover.ts`
2. Настрой цепочку: `providers: ['claude', 'ollama', 'gemini']`
3. Намеренно сломай первого — передай несуществующий бинарник первым в цепочке
4. Убедись что Kitana переключилась на следующего
5. Выведи лог переключений

**Результат:**

```bash
npx tsx src/11-failover.ts
# → [kitana] trying: fake-provider... ❌ not found
# → [kitana] trying: ollama... ✅
# → [ollama] "Вот мой ответ..."
```

> Скелет: `examples/03-kitana/failover.ts`

## 3.4 Библия проекта — бонус 📖

**Шаги:**

1. Создай файл `src/12-bible.ts`
2. Возьми Lead Finder из задания 2.4
3. После каждого агента записывай в `.kitana/bible/progress.md`:
   - что сделал агент
   - ключевой результат (топ лиды / офферы)
   - какой провайдер использовался
4. Намеренно "упади" в середине пайплайна — прервись после аналитика
5. Перезапусти — агент должен прочитать Библию и продолжить с копирайтера

**Результат:** пайплайн возобновляется с места остановки, не начинает сначала.

```bash
npx tsx src/12-bible.ts
# → [аналитик] готово → записано в .kitana/bible/progress.md
# → [pipeline] прерван!

npx tsx src/12-bible.ts
# → [bible] найден прогресс: аналитик уже выполнен
# → [копирайтер] продолжаем с шага 2...
```

> Скелет: `examples/03-kitana/bible.ts`
