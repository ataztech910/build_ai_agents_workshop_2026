# Воркшоп: Пишем ИИ агентов с нуля

Технари, офлайн, 2 часа. Цель — уйти с пониманием как агенты устроены изнутри и с рабочим кодом под свою задачу.

---

## Блок 1 — Первый агент (35 мин)

### Задание 1.1 — Scaffolding

Создай проект с нуля:

```bash
mkdir my-agent && cd my-agent
npm init -y
npm install @anthropic-ai/claude-agent-sdk dotenv
touch agent.ts .env
```

### Задание 1.2 — Напиши агента

Агент принимает название профессии через `process.argv[2]` и возвращает **только валидный JSON**:

```json
{
  "profession": "...",
  "skills": ["...", "..."],
  "avgSalary": "...",
  "demand": "high | medium | low"
}
```

Требования:
- данные ищет через `WebSearch`
- если профессия не передана — бросает ошибку с подсказкой
- запуск: `npx tsx agent.ts "prompt engineer"`

### Задание 1.3 — Сломай агента намеренно

Поменяй по очереди и запусти после каждого изменения:

1. `maxTurns: 1` — что происходит?
2. Убери `permissionMode: "bypassPermissions"` — что меняется?
3. Напиши в `systemPrompt` противоречивые инструкции — как агент себя ведёт?

Запиши наблюдения — обсудим вместе.

## Блок 2 — Пайплайн из двух агентов (35 мин)

### Задание 2.1 — Два агента последовательно

Построй пайплайн:

**Агент 1 — Исследователь**
- вход: тема (`process.argv[2]`, например `"no-code инструменты"`)
- выход: JSON массив из 5 инструментов `[{ name, description, url }]`

**Агент 2 — Критик**
- вход: JSON из агента 1
- выход: JSON с оценкой каждого `[{ name, pros, cons, bestFor }]`

Агент 2 получает результат агента 1 как часть промпта — не через отдельный `query()` вызов.

### Задание 2.2 — Сравни подходы

Запусти оба варианта и сравни качество вывода:

**Вариант A** — один большой промпт: исследуй тему И оцени инструменты за один вызов

**Вариант B** — два отдельных агента как в задании 2.1

Что лучше и почему?

### Задание 2.3 — Параллельность (бонус)

Если агенты не зависят друг от друга — запусти их параллельно через `Promise.all()`.

Придумай задачу где это имеет смысл и реализуй.

## Блок 3 — Свой агент (25 мин)

### Задание 3.1 — Найди задачу

Возьми что-то из своей реальной работы что делаешь руками и которое можно автоматизировать. Примеры для затравки:

- читает PR и пишет review checklist
- по названию задачи пишет acceptance criteria
- парсит вакансии и оценивает по твоим критериям
- по описанию бага предлагает где искать в коде
- берёт список URL и делает саммари каждого

### Задание 3.2 — Реализуй

Минимальные требования:
- хотя бы один инструмент (`WebSearch` или `Bash`)
- структурированный JSON на выходе
- обработка ошибок — агент не должен падать молча

### Задание 3.3 — Покажи соседу

Объясни за 2 минуты:
- какую задачу решает
- почему это агент а не просто промпт
- что бы добавил если было бы ещё 30 минут

## Справка

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const msg of query({
  prompt: "твой промпт",
  options: {
    systemPrompt: "роль агента",
    maxTurns: 5,
    permissionMode: "bypassPermissions",
    allowedTools: ["WebSearch", "Bash"],
  },
})) {
  if (msg.type === "assistant") {
    for (const block of msg.message.content) {
      if (block.type === "text") process.stdout.write(block.text);
    }
  }
  if (msg.type === "result") console.log("\n✅ готово");
}
```
