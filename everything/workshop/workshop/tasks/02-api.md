## Подготовка

```bash
# Проверь .env — нужен хотя бы один из:
ANTHROPIC_API_KEY=sk-ant-...   # claude
GOOGLE_API_KEY=AIza...         # gemini (бесплатный на aistudio.google.com)
```

Если нет ни одного ключа → переходи сразу к [волне 3](./03-kitana.md).

## 2.1 Подключаем Claude API

**Шаги:**

1. Создай файл `src/05-claude-agent.ts`
2. Подключи Claude через строку модели `"claude-sonnet-4-5"` в `LlmAgent`
3. Дай агенту задачу которая требует рассуждений — например проанализировать плюсы и минусы технологии
4. Сравни ответ с дефолтным Gemini из волны 1 — что лучше для этой задачи?

**Результат:** агент работает на Claude, ответ приходит через Anthropic API.

```bash
ANTHROPIC_API_KEY=sk-ant-... npx tsx src/05-claude-agent.ts
```

> Скелет: `examples/02-api/claude-agent.ts`

## 2.2 Подключаем Gemini API

**Шаги:**

1. Создай файл `src/06-gemini-agent.ts`
2. Используй `"gemini-2.0-flash"` — быстрый и бесплатный

**Результат:** агент ищет в Google и отвечает со ссылками на источники.

```bash
GOOGLE_API_KEY=AIza... npx tsx src/06-gemini-agent.ts
```

> Скелет: `examples/02-api/gemini-agent.ts`

## 2.3 Model Routing — failover между моделями

**Шаги:**

1. Создай файл `src/07-routing.ts`
2. Настрой `ModelRouter` с двумя моделями: Claude primary, Gemini fallback
3. Намеренно передай неверный Claude API ключ
4. Убедись что ADK автоматически переключился на Gemini
5. Выведи в лог какая модель ответила

**Результат:** при падении Claude агент переключается на Gemini без остановки.

```bash
npx tsx src/07-routing.ts
# → [router] claude failed: invalid API key
# → [router] switching to gemini-2.0-flash
# → [gemini] "Вот мой ответ..."
```

> Скелет: `examples/02-api/routing.ts`

## 2.4 Реальный кейс — Lead Finder пайплайн

**Шаги:**

1. Создай файл `src/08-lead-finder.ts`
2. Возьми готовый массив из 10 фейковых комментариев (есть в скелете)
3. Напиши `SequentialAgent` из трёх агентов:
   - **Аналитик** — выбирает топ-3 лида из комментариев по заданному ICP
   - **Копирайтер** — пишет персональный оффер для каждого
   - **Валидатор** — отклоняет шаблонные офферы и просит переписать
4. Запусти и посмотри как валидатор меняет офферы

**Результат:** три агента последовательно обрабатывают комментарии, на выходе — проверенные офферы.

```bash
npx tsx src/08-lead-finder.ts
# → [аналитик] топ-3: Иван, Мария, Алексей
# → [копирайтер] написал 3 оффера
# → [валидатор] оффер для Ивана — шаблонный, переписываю...
# → готово: leads_result.json
```

**Эксперимент:** поменяй ICP и запусти снова. Агент выберет других людей из тех же комментариев.

> Скелет: `examples/02-api/lead-finder.ts`
