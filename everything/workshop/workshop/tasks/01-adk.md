# Волна 1 — Google ADK basics
> ~35 минут · без API ключей · только ADK

---

## 1.1 Первый LlmAgent

**Шаги:**

1. Создай файл `src/01-hello-agent.ts`
2. Импортируй `LlmAgent` и `Runner` из `@google/adk`
3. Создай агента с именем `hello` и инструкцией на русском
4. Создай `Runner` и запусти агента с любым вопросом
5. Выведи ответ в терминал

**Результат:** агент отвечает в терминале на твой вопрос.

```bash
npx tsx src/01-hello-agent.ts
# → агент: "Привет! Я твой первый ADK агент..."
```

> Скелет: `examples/01-adk/hello-agent.ts`

## 1.2 FunctionTool — агент с инструментом

**Шаги:**

1. Создай файл `src/02-tool-agent.ts`
2. Напиши `FunctionTool` который принимает `{ city: string }` и возвращает фейковую погоду
3. Подключи инструмент к агенту через `tools: [weatherTool]`
4. Спроси агента: *"Какая погода в Москве?"*
5. Убедись что агент **вызвал инструмент**, а не придумал ответ

**Результат:** в логах видно `tool_use: getWeather` с аргументом `{ city: "Москва" }`.

```bash
npx tsx src/02-tool-agent.ts
# → tool called: getWeather({ city: "Москва" })
# → агент: "В Москве сейчас 18°C и облачно"
```

> Скелет: `examples/01-adk/tool-agent.ts`

---

## 1.3 SequentialAgent — два агента в цепочке

**Шаги:**

1. Создай файл `src/03-sequential.ts`
2. Напиши **Агент-исследователь**: принимает тему, возвращает 3 факта в JSON
3. Напиши **Агент-редактор**: принимает факты, переписывает в один абзац
4. Оберни обоих в `SequentialAgent`
5. Запусти с темой `"квантовые компьютеры"`

**Результат:** в терминале сначала появляются факты, потом готовый абзац.

```bash
npx tsx src/03-sequential.ts "квантовые компьютеры"
# → [исследователь] { facts: [...] }
# → [редактор] "Квантовые компьютеры используют..."
```

> Скелет: `examples/01-adk/sequential.ts`

---

## 1.4 ParallelAgent — бонус ⚡

**Шаги:**

1. Создай файл `src/04-parallel.ts`
2. Возьми два независимых агента — например исследователь темы А и исследователь темы Б
3. Оберни в `ParallelAgent`
4. Замерь время через `console.time` — сравни с последовательным запуском

**Результат:** оба агента отрабатывают одновременно, время ~в 2 раза меньше.

> Скелет: `examples/01-adk/parallel.ts`
